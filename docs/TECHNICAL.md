# 기술 문서

## 롬 구조
- 게임 코드 `AE4J`. NitroFS를 ndspy로 읽고 씁니다. 대사·실황·메뉴 문자열은 arm9과 오버레이(ov000~ov009) 안 Shift-JIS 문자열, RPG 파트 스크립트 데이터에 있습니다.
- ov001~ov009는 같은 주소(0x21619c0)를 공유하는 교체형 오버레이라, 늘어난 문자열은 오버레이 끝 뒤 힙(arena) 시작점을 밀어 확보한 영역과 arm9 추가 섹션(0x21e0000)에 두고 포인터를 재배치합니다(`build.py`).

## 한글 인코딩·글꼴
- 사용된 한글 음절(약 1,130자)만 Shift-JIS 2바이트 코드에 대응시키고, 게임 폰트(NFTR)의 해당 글리프를 Galmuri11/9 비트맵으로 덮어씁니다(`nftr.py`, `bdf.py`).

## 그림 글자
| 대상 | 형식 | 처리 |
| --- | --- | --- |
| 메뉴·버튼·제목 (OBJ) | 4bpp NCGR + NCER 셀 | 셀 영역 단위로 원본 글자를 지우고 배경색·외곽선·그림자를 원본에서 추출해 한글을 그림(`gtext.py`, 사양 `gfxspec.py`·`gfxov.py`, 자동 탐지 `gfxauto.py`) |
| 장 제목 카드·미니게임 제목 (BG) | NCGR + NSCR | 타일 맵을 풀어 그린 뒤 원래 팔레트로 되돌림(`bgtext.py`, `bgspec.py`) |
| 타이틀 로고·원작 표기·결과 화면 | 헤더 없는 bg/*.bin | 공유 타일을 피해서 그리기, 팔레트 뱅크별 색 선택(`rawbg.py`) |
| 시합 배너 (킥오프! 등) | 3D 텍스처용 선형 4bpp mes.NCBR | 셀마다 블록 시작 위치를 계산해 기울인 한글 + 3중 외곽선(`mes.py`, `mestext.py`) |
| 하단 화면 안내 배너·에디트 태그 | 8bpp NCGR + 확장 팔레트 | `s8text.py` |
| 하단 경기 화면 라벨 (스코어·골라인·야드) | bg/game.bin 타일 | 실행 중 VRAM에서 얻은 맵으로 타일 위치를 찾아 교체(`gamebg.py`, `gamebg_map.json`) |

- 화면에 보이는 그림 글자가 어느 파일에서 왔는지는 DeSmuME 헤드리스 실행(`emu.py`)으로 OAM·VRAM·텍스처 VRAM을 덤프해 롬 파일과 대조해 찾았습니다(`vbg.py` 등).
